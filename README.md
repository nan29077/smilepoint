# 스마일 포인트

제휴 웹하드 포인트를 교환하고, 계좌 출금 또는 모바일 쿠폰 구매에 사용할 수 있는 로컬 체험판입니다.

## 실행

Node.js 22 이상에서 프로젝트 폴더를 열고 다음을 실행합니다.

```powershell
npm.cmd run dev
```

브라우저에서 [http://localhost:3070](http://localhost:3070)을 열고 **체험 시작하기**를 누릅니다. 패키지 설치는 필요하지 않습니다.

## 체험 흐름

1. **일반 사용자**로 접속해 그린파일 포인트 교환을 신청합니다.
2. **계정 전환**을 눌러 **웹하드 관리자**로 접속한 뒤 **교환 요청**에서 승인합니다.
3. 일반 사용자의 **내 지갑**에서 잔액을 확인합니다. **계좌 출금**을 신청하거나 **포인트 쇼핑**에서 샘플 쿠폰을 구매할 수 있습니다.
4. **최고 관리자**로 접속해 **출금 심사**에서 모의 지급을 완료하거나 반려할 수 있습니다. 사용자가 남긴 문의에도 답변할 수 있습니다.
5. 각 역할의 **프로필**에서 30종의 동물 캐릭터를 선택하거나 사진을 올릴 수 있습니다.

체험 데이터는 브라우저에 저장됩니다. 브라우저의 이 사이트 저장 데이터를 지우면 초기 상태로 돌아갑니다.

## 구현 범위

현재 출금·쿠폰·웹하드 정보는 샘플 데이터입니다. 체험 역할은 서버 인증이나 운영 환경의 접근 제어를 대신하지 않습니다. 실제 서비스에는 인증과 역할 권한, 서버 거래 원장과 감사 기록, 본인 확인, 웹하드·지급·쿠폰 공급사 연동이 필요합니다.

배너 3종과 상품 이미지, 동물 프로필 이미지는 `assets/`에 포함했습니다. 가칭 서비스명은 `catalog.js`의 `config`를 기준으로 관리합니다.
