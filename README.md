# 스마일 포인트

제휴 웹하드 포인트를 스마일 포인트로 교환하고, 계좌 출금·모바일 쿠폰 쇼핑·포인트 선물에 사용하는 서비스의 **로컬 데모**입니다. 서비스명은 가칭이며 `catalog.js`의 `config`에서 바꿀 수 있습니다.

## 실행

Node.js 22 이상에서 프로젝트 폴더를 열고 다음을 실행합니다. 패키지 설치는 필요 없습니다.

```powershell
npm.cmd run dev
```

브라우저에서 <http://localhost:3070>을 엽니다.

## 로그인

상단 **로그인**·**회원가입** 버튼으로 들어갑니다.

| 방법 | 설명 |
| --- | --- |
| 소셜 로그인 | 카카오·네이버·Google·Apple 버튼. 현재는 동의 화면 후 체험용 소셜 회원으로 로그인합니다. 실제 연동은 각 사 앱 키와 SDK 등록 후 교체합니다. |
| 이메일 로그인 | 가입한 이메일·비밀번호로 로그인합니다. |
| 테스트 계정 로그인 | 로그인 화면 하단 버튼을 누르면 바로 해당 대시보드로 이동합니다. |

| 테스트 계정 | 이메일 | 비밀번호 |
| --- | --- | --- |
| 사용자 | user@smilepoint.kr | smile1234 |
| 웹하드 관리자 (그린파일) | partner@smilepoint.kr | smile1234 |
| 웹하드 관리자 (클라우드박스) | cloud@smilepoint.kr | smile1234 |
| 최고 관리자 | admin@smilepoint.kr | smile1234 |

회원가입은 이름·이메일·비밀번호·휴대폰·추천인 코드와 필수/선택 약관 동의를 받으며, 가입 즉시 1,000 P(추천 코드 입력 시 양쪽에 500 P)를 지급합니다.

## 대시보드 기능

대시보드는 좌측 메뉴로 구성되며, 좌측 하단에 **메인으로** 버튼과 **프로필**이 고정되어 있습니다. 상단에는 알림(읽지 않은 수 표시)과 로그아웃이 있습니다.

**사용자**: 내 지갑(잔액·등급·출석·친구 초대·14일 적립 차트·사용처 차트) · 포인트 교환(웹하드 계정 연결/해제, 교환 신청) · 계좌 출금(본인 명의 계좌 인증, 등급별 수수료, 일일 한도) · 포인트 쇼핑(검색·분류·수량) · 쿠폰함(바코드, 사용 완료/만료 탭) · 출석체크(월 달력, 7일 연속 보너스) · 포인트 선물 · 거래 내역(필터·CSV) · 고객센터(1:1 문의) · 프로필(동물 캐릭터 30종, 사진 업로드 우선 적용, 알림 설정, 비밀번호 변경)

**웹하드 관리자**: 자사 개요(대기·승인·처리 시간 지표, 차트, 연동 상태) · 교환 요청(일괄 승인/반려) · 거래 내역 · 정산 및 대사(기간별, CSV) · API·연동(API 키 보기/복사/재발급, 웹훅, API 명세, 호출 로그) · 교환 정책. 자사 거래만 조회·처리할 수 있습니다.

**최고 관리자**: 운영 개요(회원·심사·출금 지표, 거래 추이, 제휴사 비중, 확인 필요 업무, 최근 가입·관리 기록) · 회원 관리(검색·필터, 회원 상세, 포인트 조정, 이용 정지) · 제휴사 관리(교환 비율·최소 금액·운영 상태) · 교환 심사 · 출금 심사(일괄 처리, 반려 사유 필수) · 전체 거래 · 쿠폰 상품(가격·재고·판매 상태) · 쿠폰 주문 · 정산 및 대사 · 고객센터 답변 · 배너·공지 · 운영 설정(수수료·한도·적립 정책·점검 모드, 데모 초기화) · 감사 기록

## 구조

```
index.html      앱 껍데기
app.js          라우팅, 이벤트, 다이얼로그
state.js        데이터 모델과 업무 규칙 (계정·세션·원장·알림·감사 기록)
catalog.js      설정, 제휴사·상품 초기값, 아이콘
views/          화면 (site: 메인·로그인·가입, user/partner/admin: 대시보드, ui: 공통 컴포넌트·차트)
assets/         배너·상품·동물 캐릭터 이미지
server.mjs      미리보기 서버 (포트 3070)
```

데이터는 브라우저 localStorage(`smilepoint-demo-v2`)에 저장됩니다. 최고 관리자 > 운영 설정의 **데모 데이터 초기화**로 처음 상태로 되돌릴 수 있습니다.

## 운영 전환 시 필요한 것

현재 인증·권한·원장은 브라우저 안에서 동작하는 데모입니다. 실제 서비스에는 서버 인증(비밀번호 해시·세션), 역할 권한 검증, 서버 거래 원장과 감사 기록, 본인 확인, 소셜 로그인 SDK, 웹하드·은행 지급·기프티콘 공급사 API 연동이 필요합니다.
